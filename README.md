# Projeto SQL — Análise de Clínica Hospitalar
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em MySQL através da criação de um banco de dados fictício de uma clínica hospitalar.

O foco principal foi aplicar conceitos de modelagem relacional, consultas SQL e análise de negócio para gerar indicadores financeiros e operacionais.

---

# 🛠️ Tecnologias Utilizadas

* MySQ
* MySQL Workbench 8.0

---

# 🗂️ Estrutura do Projeto

O banco de dados é composto pelas seguintes 5 tabelas relacionais:

* `especialidades`
* `medicos`
* `pacientes`
* `consultas`
* `pagamentos`

---

# Perguntas de Negócio Desenvolvidas

1. Qual foi o faturamento total do hospital no período?
2. Quais são os 5 médicos que mais geraram faturamento?
3. Quais especialidades geram mais faturamento e mais consultas?
4. Qual a taxa de cancelamento e não comparecimento de consultas?
5. Quais são os 5 pacientes que mais frequentam o hospital?
6. Qual é o ticket médio por consulta e por especialidade?
7. Qual forma de pagamento é mais utilizada e qual gera mais receita?
8. Qual foi a evolução de faturamento mês a mês?
9. Quais médicos possuem mais pacientes únicos atendidos?
10. Quais consultas estão com pagamento pendente ou reembolso?

Todas as tabelas foram criadas com chaves primárias, chaves estrangeiras e boas práticas de modelagem.
